Live Execution Engine

Zerodha Quant
Integration Architecture

Architecture of an automated algorithmic bridging layer that reconciles offline quantitative ML signals (XGBoost/Regression) with live brokerage portfolios via the Zerodha KiteConnect API.

1

KiteConnect Gateway

A direct OAuth gateway to the Zerodha Kite API utilizing the kiteconnect Python client. It continuously authenticates and fetches live market status, holdings, and intraday positions arrays.

2

Live State Reconciliation

Matches real-time traded instrument tokens against offline machine learning output stored in trading_signals.csv. The engine calculates P/L by reconciling API-held quantities against target ML exposures.

3

Real-Time Price Polling

Executes lightweight JSON requests to kite.quote() to fetch real-time bid/ask snapshots for dynamic mark-to-market valuations, bypassing slow historical data endpoints when live trading is active.

4

Fallback Data Pipeline

Implements an offline fallback mechanism: if the KiteConnect API rate limits are hit or the live ticker socket drops, the system gracefully falls back to querying the latest Yahoo Finance datasets.
